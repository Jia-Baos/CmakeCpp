## 代码解析
- Memento 类：用于保存文本编辑器的状态，getState() 方法用于获取文本的内容。

- TextEditor 类：作为发起人类，setText() 设置文本，getText() 获取当前文本。createMemento() 用于创建备忘录，restoreMemento() 用于恢复之前保存的状态。

- Caretaker 类：看护者类负责管理备忘录，它可以保存多个备忘录（保留多个历史状态），并根据索引恢复指定的备忘录。

主函数：

- 创建一个 TextEditor 实例，并进行状态设置和修改。

- 每次修改文本后，保存当前状态到 Caretaker 中。

- 可以随时通过 Caretaker 恢复之前保存的状态。

## 优点

- 封装性：备忘录模式使得状态的保存与恢复完全独立于外部类，保持了对象状态的封装性。

- 历史记录管理：可以通过管理备忘录对象，实现对历史状态的管理和恢复。


- 支持撤销操作：对于编辑器或其他有状态的应用，备忘录模式非常适合实现撤销/重做功能。

## 缺点

- 内存开销：如果需要保存大量的状态，可能会消耗大量内存，尤其是在保存频繁变化的对象状态时。

- 代码复杂性：引入备忘录对象和看护者对象后，代码的复杂度和维护难度会增加。

## 适用场景

- 撤销操作：文本编辑器、绘图程序等支持撤销/重做操作的应用程序。

- 版本管理：需要保存对象的多个状态，并能够恢复到历史状态的场景。

- 游戏中存档：保存游戏的中间状态，以便玩家可以恢复到某个存档点。
